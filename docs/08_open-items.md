## C. 実装上の既定（変更する場合はユーザに相談）

- 後から届いたオフライン分で、過去の連続日数ボーナスを遡って修正しない（`03_point-rules.md` 4章）。ゲームが古い順に送るため、通常は問題にならない。
- 端末時刻の妥当性チェックに外れたプレイは、サーバ受信日で処理し `clock_suspect` を付ける（ポイントは付与する）。
- 自己ベストの判定履歴は全期間・全モード共通。

- 自己ベストの到達が月の上限で0ptに切り詰められた場合も、到達は「達成済み」として記録する（生涯1回のため、後から再付与しない）。
- 台帳の調整の冪等キー `adjustment_id` は `ledger_entries.transaction_id` に保存する。
- 実装済みの決定（2026-11-10、ユーザ承認）：A1 = 推奨スタック、実行環境 = Docker Compose（A2）。A3〜A6 はフェーズ2で次のとおり実装（2026-11-11、推奨どおり。変更があれば相談）：
  - A3：初回起動時にサーバのアドレスを手入力（例 `192.168.1.10:8000`）。QRコード読み取りは未実装。入力欄の既定値は `http://192.168.0.2:8000/`（2026-11-11 ユーザ指定。ビルド時に `-PkotsuDefaultServer=...` で変更可。前回入力した値があればそちらを優先）。Android は `.local`（mDNS）名を解決できない機種があるため、**固定のローカルIP** を推奨。
  - A4：HTTP。`networkSecurityConfig` で平文通信を許可（家庭内LAN限定のため全ホスト許可）。
  - A5：励ましの言葉は仮の文面25個（`android/game-kuku/.../Quiz.kt` の `ENCOURAGEMENTS`）。家庭で差し替えてよい。子供の表示名は管理画面で登録したもの。
  - A6：効果音は `android/tools/gen_sounds.py` で合成した自作音（外部素材なし、ライセンス不要）。

- フェーズ2.5（2026-11-12 ユーザ承認）：ランチャー方式で自動更新する。子供の端末の Android の版は不明（極端に古くはない）のため、版の差で動作を変える（12以上は確認なし、それ未満は確認画面）。端末は **ファミリーリンクで管理** されているため、ランチャーに「提供元不明のアプリ」の許可を与えるには、保護者側のファミリーリンクでも許可が必要な場合がある（管理画面の手順に記載）。
  - 署名鍵はリポジトリ外（`~/.kotsukotsu-secrets/`）。紛失すると全端末で入れ直しになるため、別機器にバックアップする。
  - デバッグ版で入れた九九（〜1.0.1）は、署名が違うため一度アンインストールしてランチャーから入れ直す。

- フェーズ2.6 おしらせ通知（2026-11-17 ユーザ承認、すべて推奨案）：「やっていない」は今日を含めて数える（既定1日）。文言は管理画面で編集。時刻は平日と土日祝で分ける。通知は子供の端末だけ。
  - 外部のプッシュ通知は使わず、九九アプリが端末内で予約する（家庭内LAN限定のため）。
  - 祝日は外部ライブラリを使わずサーバで計算する（祝日法の規則、春分・秋分は近似式で 2099年まで）。法改正で祝日が変わったときはサーバの計算を直す。
  - 子供の端末の Android の版は未確認。13 以上なら通知の許可が要る。
- フェーズ4 親用アプリ（2026-11-14 ユーザ承認、すべて推奨案）：外出先での引き出し・調整を主目的とした簡単な仕様。未送信の操作は削除せず逆向きの調整で取り消す。端末の保護は画面ロックに任せる。配布は管理画面の「ゲーム配信」（`parent-app`）からブラウザでダウンロード。親ごとに自分のIDでログイン。
